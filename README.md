# ระบบช่วยหาคู่สลับคาบสอน

เครื่องมือช่วยครูหา "คู่สลับคาบ" เวลาต้องลา — ป้อนว่าจะลาวันไหน คาบไหน แล้วโปรแกรมจะจัดอันดับครูที่สลับคาบด้วยได้ พร้อมคะแนนความเหมาะสม เบอร์ติดต่อ วันคืนคาบ และพิมพ์ใบแลกคาบให้เสร็จ

**เปิดใช้งาน → https://zenithjuno.github.io/schedule-swap-pp/**

---

## จุดสำคัญที่สุด: ข้อมูลของคุณไม่ถูกส่งไปไหนเลย

โปรแกรมนี้เป็นไฟล์ HTML ไฟล์เดียว ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล ไม่มีบัญชีผู้ใช้ ในโค้ดไม่มี `fetch` ไม่มี `XMLHttpRequest` ไม่มีการเรียก URL ภายนอกแม้แต่ที่เดียว — ฟอนต์ ไลบรารีอ่าน Excel ทุกอย่างฝังอยู่ในไฟล์หมดแล้ว

แปลว่า **ตารางสอนและเบอร์โทรครูที่คุณนำเข้า จะอยู่ใน `localStorage` ของเบราว์เซอร์เครื่องคุณเท่านั้น** ไม่ขึ้นไปที่ GitHub ไม่ขึ้นไปที่ไหนทั้งนั้น

ไฟล์ `index.html` ใน repo นี้จึงเป็น **ไฟล์ต้นฉบับเปล่า** — ไม่มีข้อมูลครูจริงฝังอยู่ ผู้ใช้แต่ละคนนำเข้าข้อมูลของตัวเอง

> ⚠️ **ห้าม commit ไฟล์ที่มีข้อมูลจริง** ไฟล์ `.html` ที่ได้จากปุ่ม "สร้างไฟล์พร้อมใช้", ไฟล์ backup `.json`, และไฟล์เบอร์โทร `.xlsx` — ทั้งหมดมีชื่อและเบอร์ครูจริง `.gitignore` กันไว้ให้แล้ว แต่ตรวจก่อน push ทุกครั้ง

---

## เริ่มใช้ครั้งแรก

1. เปิดลิงก์เว็บด้านบน (หรือดาวน์โหลด `index.html` แล้วดับเบิลคลิกเปิดก็ได้ ทำงานแบบออฟไลน์เหมือนกัน)
2. ไปแท็บ **ตั้งค่า** → ปุ่ม **แม่แบบตารางสอน** และ **แม่แบบเบอร์โทร** เพื่อโหลดไฟล์ Excel เปล่า *(หรือใช้ไฟล์ใน `templates/` ก็ได้ เหมือนกัน)*
3. กรอกตารางสอนลงแท็บ `VERIFIED_DATA` แล้วนำเข้า
4. นำเข้าไฟล์เบอร์โทร
5. เริ่มค้นหาคู่สลับคาบได้เลย

ถ้าเคยใช้อยู่แล้วและมีไฟล์ backup `.json` เดิม — ไปที่ **ตั้งค่า → กู้คืนข้อมูล** แล้วเลือกไฟล์นั้น ข้อมูลทั้งหมดกลับมาทันทีโดยไม่ต้องรีโหลด

📄 คู่มือฉบับหน้าเดียวสำหรับพิมพ์แจก: [`docs/quickstart_swap_TH.pdf`](docs/quickstart_swap_TH.pdf)

## เรื่องที่ต้องรู้เมื่อใช้ผ่านเว็บ (ไม่ใช่เปิดไฟล์ตรง ๆ)

| เรื่อง | รายละเอียด |
|---|---|
| ข้อมูลผูกกับเบราว์เซอร์ | ข้อมูลเก็บแยกตาม **เบราว์เซอร์ + เครื่อง** เปิดที่โรงเรียนกับที่บ้าน = คนละชุด ต้องย้ายด้วยไฟล์ backup |
| ล้างข้อมูลเบราว์เซอร์ = ข้อมูลหาย | "Clear browsing data" หรือโหมดไม่ระบุตัวตน จะลบ `localStorage` ทิ้ง — **กด "สำรองข้อมูล" เก็บไฟล์ `.json` ไว้เสมอ** |
| พื้นที่เก็บ | ตารางหนึ่งภาคเรียน (3,823 คาบ) + เบอร์ 150 คน ใช้ราว 1 MB จากโควตาปกติ 5–10 MB — สบาย ๆ |
| เบราว์เซอร์ | Chrome / Edge คือเป้าหมายหลักที่ทดสอบไว้ (Safari มีข้อจำกัดเรื่องพื้นที่เก็บของหน้า `file://`) |
| การพิมพ์ | ใบแลกคาบและตารางสอนออกแบบมาสำหรับ A4 + TH Sarabun ฝังในไฟล์แล้ว สีตารางย้ายคาบเข้า/ออกตั้ง `print-color-adjust:exact` ไว้ให้ติดตอนพิมพ์ |

## แจกให้เพื่อนครูใช้

สองทางเลือก:

- **ส่งลิงก์เว็บ** — เพื่อนต้องนำเข้าตารางเอง
- **ตั้งค่า → "สร้างไฟล์พร้อมใช้ (.html)"** — ได้ไฟล์เดียวจบที่มีตารางสอนและเบอร์โทรฝังมาด้วย (แต่**ไม่มี**บันทึกการสลับของคุณ) เพื่อนดับเบิลคลิกเปิดได้เลย ไม่ต้องต่อเน็ต

⚠️ ไฟล์จากวิธีที่สองมีข้อมูลส่วนบุคคล — ส่งตัวต่อตัว อย่าอัปขึ้นที่สาธารณะ และอย่า commit

## ตรวจสอบว่าโปรแกรมยังคำนวณถูก

ในโปรแกรมมีปุ่ม **ตั้งค่า → ตรวจสอบระบบ** ซึ่งรันชุดทดสอบแช่แข็ง (oracle fixture) 21 เคส เทียบผลลัพธ์ทีละช่อง 1,455 ช่อง ถ้าขึ้นเขียวครบ 21/21 แปลว่า engine ยังให้ผลตรงกับที่ตรวจรับไว้ตั้งแต่ต้น

ชุดทดสอบนี้สร้างจากข้อมูลจริง แต่**เปลี่ยนชื่อครูเป็นนามสมมติ** (`ครูทดสอบ 001`–`110`) แล้ว โดยยึด `teacher_id` เป็นหลัก — เครื่องมือจัดอันดับใช้ `teacher_id` ไม่ใช่ชื่อ ผลทดสอบจึงไม่เปลี่ยน ตัวเลข golden ยังเป็น **104/103/89/87/74** เท่าเดิม

## เปิดเว็บด้วย GitHub Pages

ตั้งไว้แล้วที่ **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**
ทุกครั้งที่ push ขึ้น `main` เว็บจะอัปเดตเองภายในไม่กี่นาที

repo แบบ public ใครก็เปิดเว็บนี้ได้ — แต่เห็นแค่ **โปรแกรมเปล่า** ไม่มีข้อมูลโรงเรียน ซึ่งเป็นเรื่องปกติและปลอดภัย

## เทคนิค

ไม่มี build step ไม่มี dependency ไม่มี framework แก้ `index.html` แล้วเปิดดูได้เลย ข้างในเรียงเป็นสเตจตามลำดับที่สร้างจริง มีคอมเมนต์ `STAGE nn` คั่นไว้ และเปิด API ผ่าน `window.__SWAP_*` สำหรับทดสอบแบบ headless
