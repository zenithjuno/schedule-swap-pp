# เชื่อม UI กับ engine จัดคาบสอน

ไฟล์ `js/modes.js` เปิด API ที่ `window.SWAP` หลัง `core.js` และ `dynamic.js` หน้าเว็บหลักโหลดไว้ให้แล้ว ให้เรียก `S.activeModes(options)` ใหม่เมื่อตาราง รอบลา ทะเบียน หรือภาคเรียนเปลี่ยน ผลค้นหาและพรีวิวอ่านข้อมูลอย่างเดียว วิธีบันทึกคือ `S.commitMode(kind, request, options)` ซึ่งค้นซ้ำจากภาคเรียนที่เปิดอยู่ก่อนเขียน

`options` รองรับ `skipDates` (วันงดกิจกรรมแบบ `YYYY-MM-DD`), `departments` (รหัสครู → รหัสกลุ่มสาระจริง) และ `teachers` (รายชื่อเพิ่มเติมเป็น `{teacherId, teacherName}` ถ้าครูไม่มีแถวสอน) ใช้ชุดตัวเลือกเดียวกันตอนค้นและบันทึก วันเป็น ค.ศ. คาบรับได้ทั้งเลขและสตริง ผลลัพธ์คืนคาบเป็นสตริง การตรวจชนอิงข้อมูลภาคเรียนที่โหลดในเบราว์เซอร์นี้

## อยากได้คาบนี้

เรียก `findTargetSwaps({teacherId, group, date, period, from?, to?, targetTeacherId?, targetGroup?, skipDates?, dateProposed?})` ใช้รหัสกลุ่มเรียน เช่น `4.2` หรือชื่อชั้น–ห้อง เช่น `ม.4/2` ถ้าพบหลายครูหรือหลายกลุ่ม คืน `code: 'ambiguous-target'` พร้อม `targets` ให้เลือกแล้วเรียกใหม่

ผลสำเร็จมี `target` และ `options` แต่ละตัวเลือกมี `offer` (คาบที่ยกให้), `entry` (ข้อเสนอ), `impact` (ภาระก่อนและหลัง), `warnings` และ `lunch` หากไม่ระบุช่วงค้นหา จะค้นสัปดาห์ของคาบเป้าหมายและสัปดาห์ถัดไปภายในภาคเรียน

ส่งข้อมูลค้นเดิมพร้อม `targetTeacherId`, `targetGroup`, `offerDate`, `offerPeriod` และ `semesterLabel` ไปที่ `commitMode('target-swap', request, options)` ค่าในทะเบียนใช้ `kind: 'แลกคาบ'` และ `workflow: 'target-swap'` โดย `date_absent/per_give` เก็บคาบที่ผู้ขอยกให้ และ `date_back/per_back` เก็บคาบที่อยากได้ ใช้ข้อความตามหน้าที่ของทั้งสองคาบเมื่อนำไปแสดงหรือจัดเอกสารสำหรับโหมดนี้

ใช้ `teacherPreview(entries)` เพื่อได้ `before`, `after` (ชุดรายการสำหรับวาดตาราง) และ `tables` (คู่ `{teacherId, weekStart}`) ส่งแต่ละคู่ให้ตัวแสดงตารางครูเดิม `APP.ttWeek(teacherId, weekStart, entries)` แลกข้ามสัปดาห์หนึ่งคู่ครูได้สี่ตาราง

## หาครูสอนแทน

เรียก `planSubstitutes({teacherId, date?, selectedPeriods?, leaveMode?, assignments?, scope?, department?, query?, skipDates?, dateProposed?})` ค่าเริ่มต้นคือวันนี้และทุกคาบที่เข้าเงื่อนไข หากส่ง `selectedPeriods` เช่น `[2,5]` ให้เลือกเฉพาะคาบนั้น ค่า `leaveMode` รองรับ `ทั้งวัน`, `ครึ่งเช้า`, `ครึ่งบ่าย`, `บางคาบ` หากมีรอบลาเดิม ให้ใช้ขอบเขตเดิมเมื่อไม่ได้ระบุคาบหรือโหมดใหม่ กรณีระบุคาบเองจะใช้ `บางคาบ` โดยปริยาย

- `scope` ใช้ `all`, `same-department` (กลุ่มที่ผู้ลาสอน), `department` (กลุ่มใน `department` เช่น `ค`) หรือ `lesson-department` (กลุ่มของวิชาในแต่ละคาบ) กลุ่มสาระมาจากอักษรตัวแรกของรหัสวิชาที่ครูสอน (`S.deptOf`, `S.deptSets`) เว้นแต่ส่ง `departments` มาเอง ใช้ `query` ค้นชื่อและรหัสครู เมื่อมี `query` จะค้นจากครูทุกคนโดยไม่สน `scope` หากต้องการกลุ่มสาระเดียวกันแต่ขาดข้อมูลของผู้ลา ให้ใช้ `departmentMissing` แจ้งผู้ใช้และเสนอเปิดตัวกรองครูทั้งหมด
- `assignments` เป็นคาบ → รหัสครู เช่น `{2: '0001'}` ตัวกรองจำกัดรายการที่แสดง ส่วนผู้ที่เลือกไว้แล้วจะถูกตรวจความพร้อมโดยตรง
- ผู้สมัครแต่ละคนมี `score` และ `scoreParts` จาก `S.subScore` (คะแนนเริ่มต้น + ภาระสัปดาห์หลังรับคาบ − เกินต่อวัน − คาบติดยาว + สอนห้องนี้อยู่แล้ว + กลุ่มสาระเดียวกัน − งดประชุม − ตรงพักกลางวัน) เรียงตามคะแนน น้ำหนักอยู่ใน settings `SUB_*`
- `slots` แสดงบทเรียน สถานะ `unselected / uncovered / assigned / covered / conflict` และรายชื่อครูพร้อมภาระสอน `uncovered` คือคาบที่เลือกและยังขาดคน ส่วน `issues` ระบุรายการที่ต้องแก้ก่อนบันทึก
- เรียก `commitMode('substitute', request, options)` พร้อม `semesterLabel` เพื่อบันทึกคาบที่เลือกครูแล้วเป็น `kind: 'สอนแทน'` โดยไม่มีวันหรือคาบคืน การบันทึกรวมรอบลาตามที่ระบุ จึงกลับมาเติมคาบที่ยังขาดคนได้ ส่ง `recordLeave: false` หากรอบลาดูแลผ่านขั้นตอนอื่น

## ตารางเรียนฉบับปรับสำหรับนักเรียน

เรียก `studentTimetable({group, from, to?, annotations?, updatedAt?})` ช่วงวันที่เลือกสัปดาห์ที่จะแสดงทั้งสัปดาห์ภายในภาคเรียน ผลลัพธ์มี `weeks`, `days`, `cells`, `lessons`, `changes` (ก่อน–หลังและคาบต้นทาง) และ `updatedAt` มุมมองนี้รวมรายการที่อนุมัติแล้วของชั้น–ห้องหรือกลุ่มเรียน คาบสอนแทนใช้วิชาและห้องเดิมกับชื่อผู้สอนแทน เรียกด้วยช่วงที่ครอบคลุมทั้งสองวันเพื่อแสดงการแลกข้ามสัปดาห์

ให้ UI ใช้ `canExport` เปิดปุ่มดาวน์โหลด PNG และแสดง `conflicts` ให้ผู้จัดแก้เมื่อส่งออกไม่ได้ ป้ายสอบหรือประกาศเฉพาะคาบรับจาก `annotations: [{group, date, period, label}]` ซึ่งผู้จัดเป็นคนระบุ โมเดลตารางนักเรียนมีเฉพาะข้อมูลการเรียน ไม่มีเบอร์ติดต่อหรือเหตุผลการลา
